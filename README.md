# Kuziya на Render

1. Создайте приватный репозиторий только для этого пакета и поместите содержимое папки в его корень.
2. В Render выберите New → Blueprint и подключите этот репозиторий. План Free и команды запуска заданы в render.yaml.
3. После успешного развёртывания откройте HTTPS-адрес onrender.com. Запрос GET /online/health должен вернуть 204 и заголовок X-Kuziya-Service: 1.
4. Чтобы включить запасной маршрут для голоса и экрана, задайте в настройках окружения сервиса KUZIYA_CF_TURN_KEY_ID и KUZIYA_CF_TURN_API_TOKEN от Cloudflare Realtime. Токен не нужно добавлять в репозиторий или EXE.
5. Соберите клиент из основной папки Kuziya командой powershell -ExecutionPolicy Bypass -File .\build-exe.ps1 -OnlineUrl https://ВАШ-АДРЕС.onrender.com. Проверьте вход, звук и показ экрана с двух ПК в разных сетях.

Этот пакет содержит только публичную сигнализацию и её страницы. Клиентские EXE, настройки локального туннеля, журналы и секреты в него не входят. Render Free при простое может засыпать. Адрес сохраняется после пробуждения. При перезапуске коды открытых комнат истекают.
